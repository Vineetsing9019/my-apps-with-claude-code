# My Apps with Claude Code

I look for small everyday problems people ignore and turn them into app ideas. Each idea is built as a working prototype that runs on my laptop, with Claude Code. I use AI the right way: as a tool to build better and faster, while the ideas, the decisions and the checking are mine.

## Apps

| App | The everyday problem it solves | Tech |
|---|---|---|
| [Salon Chair Queue](salon-chair-queue/) | Not knowing how long you'll wait at the salon: see free chairs live and book the next one | Node.js (no dependencies), HTML, CSS, JavaScript |
| [Antakshari Mehfil](mehfil-antakshari/) | Antakshari only works when everyone is in one room: sing together online, with live voice and turns | Node.js, Express, Socket.IO, WebRTC, HTML, CSS, JavaScript |

More ideas coming.

Each app has its own folder with a README, screenshots and how to run it.
